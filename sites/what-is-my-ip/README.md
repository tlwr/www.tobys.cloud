# what-is-my-ip.tobys.cloud

Returns the client IP (`CF-Connecting-IP`), as plain text or JSON.

```
curl https://what-is-my-ip.tobys.cloud/
curl -H 'Accept: application/json' https://what-is-my-ip.tobys.cloud/
```

## Develop

```bash
npm ci
npm run dev
npm test
```

## Deploy

```bash
npm run deploy
```
